# Discrete Math Quest — Member 1

This is the Member 1 implementation for the Discrete Mathematics Gamified Application.

## Member 1 responsibilities
- Common frontend
- Home page
- Game selection page
- Navigation
- Instructions
- Score
- Timer
- Lives
- Progress bar
- Result page
- Logic & Truth Dungeon
- 20 logic questions
- AND, OR, NOT, implication
- Truth tables
- Modus Ponens
- Modus Tollens
- Resolution

## Technology
- React
- JavaScript
- CSS
- React Router
- Vite

## Run locally

1. Install Node.js.
2. Open this project folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost address shown by Vite.
